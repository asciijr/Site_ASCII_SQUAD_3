# Diretrizes de Engenharia — Site ASCII

## Projeto
Landing page institucional da ASCII Empresa Júnior.

## Stack
- React
- TypeScript
- Vite

## Arquitetura
- Seguir Atomic Design.
- Organizar componentes em atoms, molecules,
  organisms e templates.
- Manter páginas em pages/.
- Centralizar chamadas externas em services/.

## Código
- Utilizar inglês em nomes de variáveis,
  funções, componentes e arquivos.
- Utilizar TypeScript com tipagem explícita.
- Evitar duplicação de componentes.
- Priorizar responsividade e acessibilidade.

## Segurança
- Não versionar credenciais ou arquivos .env.
- Não inserir dados reais de clientes em testes.

## Git
- Seguir Conventional Commits.
- Não realizar commits diretamente em main ou develop.
- Utilizar Pull Requests para integração.
